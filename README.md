Remind Me is a lightweight demo application designed to showcase my architectural approach and coding practices in Kotlin.

The app retrieves event data from the user’s contact provider (e.g., birthdays) and combines it with custom events managed within the application. It then schedules timely reminders based on this aggregated dataset.

The project illustrates clean code principles, modular architecture, and platform-integrated event handling on Android.
